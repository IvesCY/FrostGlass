# 开发记录

这个项目从一句“我想要一个遮挡屏幕内容的功能”开始，最后变成了现在这个可调磨砂、鼠标穿透、带 Windows 风格标题栏的便携工具。这里记录主要的技术选择和走过的弯路。

## 时间线

### 1. 最早的磨砂原型

最初使用 Windows 的 Acrylic（`SetWindowCompositionAttribute`）实现毛玻璃。它看起来很好，但模糊强度是系统固定的，重到完全看不清后面的内容；透明度只能改变颜色深浅，不能真正调节可读性。

结论：需要自己控制画面和模糊强度。

### 2. 实时预览与可调清晰度

改成在玻璃内部渲染一份实时的、本机屏幕采样：

1. 采样玻璃背后的屏幕区域；
2. 用本地 box blur 处理，并做两层模糊之间的插值，让清晰度调节更细腻；
3. 叠一层可调的雾色；
4. 约每秒刷新 10 次。

采样时通过 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` 临时把自己排除掉，避免拍到玻璃本身造成递归。画面只在内存处理，不保存、不联网。

清晰度滑块后来又改成了 40%–100%：数值越高越清晰。这样既能让屏幕前的人辨认内容，也能让稍远的人难以阅读。

### 3. 永不挡鼠标

实际使用中发现，一个 topmost 的覆盖层即使用 `WS_EX_TRANSPARENT`，有时仍然会挡住下方窗口的点击和滚轮。

最终稳定下来的结构是：

- **玻璃主体** (`FrostPane`)：`WS_EX_LAYERED | WS_EX_TRANSPARENT`，系统级鼠标穿透；负责实时预览。
- **标题栏** (`PaneBar`)：独立的小窗口，只覆盖顶部标题栏区域，负责拖动、顶部缩放和按钮。
- **边框** (`PaneResizer`)：几乎不可见的窗口区域，只在左右边缘和底部边缘接收鼠标，用来缩放；中间是空的。
- 键盘焦点由 `WS_EX_NOACTIVATE` 保证不会从下方窗口抢走。

这样玻璃中间是真的穿透，标题栏和边框又可以直接操作。

### 4. 像普通 Windows 窗口

标题栏使用了和 Windows 标题栏类似的布局：

- 左侧玻璃图标与「毛玻璃」标题
- 右侧设置（滑杆）、最小化、关闭
- 半透明背景，鼠标移上去自动变清晰
- 拖标题栏移动；拖四边/四角缩放

为了降低存在感，标题栏空闲时的整体透明度较低；鼠标移入时提升透明度，离开后恢复。

### 5. 其他细节

- 框选界面使用全屏截图 + 暗色蒙层，可以显示上次区域的虚线框。
- 由于 WinForms 在部分 DPI 配置下 `DeviceDpi` 不准确，绘制尺寸改用 `GetDpiForWindow` 计算。
- 框选窗口需要用 `AttachThreadInput`/`SetForegroundWindow` 确保可以接收键盘输入（Enter / Esc）。
- 设置保存在 `%APPDATA%\FrostGlass\settings.ini`。
- 使用一个可配置的按住组合键（默认 `Ctrl+Alt`）也可以从玻璃内部拖动/缩放，作为标题栏之外的选择。

## 架构

```
FrostPane (玻璃主体，系统级穿透，渲染实时磨砂)
├─ 每秒约 10 次采样屏幕
├─ FastBlur → 清晰度调节 → 叠雾色
└─ PaneBar (独立标题栏，按钮/拖动/顶部缩放)
   PaneResizer (边缘透明输入窗口，负责左右/底部缩放)
```

相关类：

| 文件 | 作用 |
| --- | --- |
| `src/FrostPane.cs` | 玻璃主体、实时预览、穿透、调整快捷键 |
| `src/PaneBar.cs` | 标题栏、按钮、拖动、顶部缩放、鼠标悬停淡入 |
| `src/PaneResizer.cs` | 边缘缩放输入层 |
| `src/SelectorForm.cs` | 全屏框选与上次区域 |
| `src/FastBlur.cs` | 本地快速模糊 |
| `src/SettingsPanel.cs` | 设置面板 |
| `src/TrayAppContext.cs` | 托盘、生命周期、全局快捷键 |
| `src/AppSettings.cs` | 设置持久化 |

## 已知限制

- 实时预览约 10 fps，画面会有一点延迟；快速滚动和视频会轻微卡顿。
- 视觉遮挡不是安全边界；某些窗口抓取方式可能绕过。
- 主要面向 Windows 11；Windows 10 2004+ 基本可用。依赖 .NET Framework 4.8。
- 多显示器和混合 DPI 环境尚未充分测试。
- 标题栏和边框会接收鼠标，这是为了能拖动/缩放；只有玻璃中间完全穿透。
